# External Attack Surface Management (EASM) Playbook

This repository documents the **classic EASM framework** and its **evolution with AI**.  
It is organized into sections for **Classic Playbooks**, **Threat Intel Sources**, **Modern AI-driven EASM**, and **Templates/Examples**.

## 📂 Structure
- `classic/` → Classic EASM playbooks, Threat Intel, and XTI framework  
- `modern/` → Modern toolkits and AI integrations  
- `ai/` → EASM with AI (2025 and beyond)  
- `templates/` → CSV/MD templates to track assets and findings  
- `examples/` → Example datasets  

## 🧠 What You’ll Learn
- How to **enumerate attack surface** (domains, subdomains, IPs, assets)  
- Where to gather **threat intelligence** (Shodan, hacker forums, ransomware blogs, etc.)  
- How **EASM, DRP, and CTI** fit into the **XTI model**  
- How **AI tools (LLMs, automation, enrichment)** change the workflow in 2025  

This repo is meant as a **learning lab + knowledge base** for cyber defense
