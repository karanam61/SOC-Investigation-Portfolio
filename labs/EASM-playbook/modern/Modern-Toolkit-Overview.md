# Modern Toolkit for EASM (2025)

The field has evolved beyond classic tools like Sublist3r.

### 🔹 Attack Surface Discovery
- **Amass** → Deep subdomain enumeration (active/passive modes).
- **Assetnote ASM** → Continuous commercial ASM platform.
- **SecurityTrails API** → High-fidelity subdomain + IP history.

### 🔹 Vulnerability Intelligence
- **Nuclei** → Automated CVE scanning with templates.
- **ProjectDiscovery stack** → Tools for recon + vuln discovery.

### 🔹 Threat Feeds
- **Oligo, Pulsedive, Recorded Future** → curated feeds.
- **GreyNoise** → filters benign internet noise from attacker IPs.

### 🔹 Automation
- **Python + APIs** for Shodan, Censys, VirusTotal.
- **SOAR platforms** to auto-enrich & triage findings.

✅ In 2025 → Most orgs use a mix of **open source + SaaS ASM platforms** integrated into SOC pipelines.
